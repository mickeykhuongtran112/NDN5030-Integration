Direct .NET SDK

Integrate Ndn5030.Client 0.8.2 with a .NET 10 application. One ReaderClient owns one reader connection.

Package installation

Create a .NET 10 console project, or start from the ready-made project in the sdk\ReadTags folder of the package. Add the sdk folder of the extracted package as a local NuGet source; replace the path below with your own. Ndn5030.Client depends on System.IO.Ports 10.0.0, so nuget.org or your internal feed must also be reachable during restore.

PowerShell
dotnet nuget add source "D:\NDN5030\sdk" --name NDN5030
dotnet add package Ndn5030.Client --version 0.8.2

Bounded inventory example

Save the following as Program.cs. The first argument is the reader address: a WSS URL for Ethernet, or a USB COM port name such as COM7. The second argument is the path of the host.json file of the reader. The tag callback is called from the SDK loop that receives reader notifications, so it must return quickly.

C#
using Ndn5030.Client;

string endpoint = args[0];
string credentials = args[1];
await using var reader = endpoint.StartsWith("wss://", StringComparison.OrdinalIgnoreCase)
    ? new ReaderClient(ProvisionedIdentity.Load(new Uri(endpoint), credentials))
    : ReaderClient.FromUsb(ProvisionedIdentity.LoadUsb(endpoint, credentials));
var hello = await reader.ConnectAsync();
var config = await reader.GetReaderConfigurationAsync();
Console.WriteLine($"{hello.BoardId}, firmware {hello.Firmware}, ceiling {config.PowerLimitDbm} dBm");
using var stop = new CancellationTokenSource();
Console.CancelKeyPress += (_, e) => { e.Cancel = true; stop.Cancel(); };
var request = new InventoryRequest(Guid.NewGuid(), [1, 2, 3, 4], MaxDurationMs: 5000) { Data = "epc_tid" };
var result = await reader.ScanAsync(request,
    tag => Console.WriteLine($"ANT{tag.Antenna}   {tag.EpcHex}   {tag.TidHex}"), stop.Token);
Console.WriteLine($"{result.Session.Reason}   {result.ReceivedCount}/{result.Session.LastSeq}   complete={result.DataComplete}");
await reader.ReleaseLeaseAsync();

Note. A reader serves one controller at a time. Select Disconnect in TCPHost before you run the example on the same reader.

PowerShell
dotnet run -- wss://192.168.77.2:8443/v1/control D:\station\host.json

ScanAsync acquires the lease, starts inventory, receives the tag notifications and, at the end, checks that it received every sequence number up to the last one the reader reported. Cancelling the token you pass to it sends Stop for that scan; the call still returns the final result. ReceivedCount counts observations; DataComplete requires a successful terminal result, no sequence gaps, zero reported drops and zero input errors.

Wait for the reader to be ready

After power-on or a restart the reader reports initializing while it prepares the RFID module. AcquireLeaseAsync and ScanAsync raise ReaderRpcException with code -32001 and message busy in that time. Wait for idle after ConnectAsync.

C#
ReaderStatus status;
while ((status = await reader.GetStatusAsync()).State is not ("idle" or "unknown"))
    await Task.Delay(100);
if (status.State == "unknown")
    throw new InvalidOperationException($"Reader fault: {status.Reason}");

Configuration calls

C#
await reader.AcquireLeaseAsync();
var power = (await reader.GetPowerAsync()).Decode<int[]>();
Console.WriteLine(string.Join(", ", power));
await reader.ReleaseLeaseAsync();

Call AcquireLeaseAsync before module operations. GetReaderConfigurationAsync returns the cached configuration. GetPowerAsync queries the RFID module. To recover from a lost reply when you change a setting, create a UUID yourself, save it and pass it to CallModuleAsync(operation, args, operationId); GetModuleResultAsync then returns the stored result for that UUID.

Exceptions and timeouts

ExceptionRaised whenAction
ReaderRpcExceptionThe reader answered with an error. Code and Message hold the JSON-RPC values.Handle by code. See Diagnostics and recovery.
ReaderTransportExceptionNo reply arrived: the request timed out, the connection closed or you cancelled the call. MayHaveExecuted is true when the request was already sent.Check GetStatusAsync or GetModuleResultAsync with the same UUID before repeating the action. If the connection has closed, create a new client and connect again.
ModuleOperationExceptionRequireSuccess() or Decode<T>() was called on a module result whose outcome is not success. Result holds the full result.Read Result.Outcome, Result.Reason and Result.Steps.
NotSupportedExceptionThe operation is not advertised by the connected reader.Use the functions listed for NDN5030.
InvalidDataExceptionThe reader reports another API major version or RFID module family, or a read-back or upload offset does not match.Check firmware and SDK versions. Read the status again.
InvalidOperationExceptionA function that needs the lease was called before AcquireLeaseAsync, ConnectAsync was called twice on one client, or a second event consumer was started.Correct the call order.
ArgumentExceptionThe InventoryRequest is invalid (1 to 4 different antennas, duration 1 to 3600000 ms) or asks for tag data the reader does not advertise.Correct the request.

A request waits 5 seconds for its reply. module.call and ota.finish wait 12 seconds. A client whose connection has closed cannot be reused. Create a new ReaderClient.

Multi-reader concurrency

Create one ReaderClient per reader. Verify each board ID before starting concurrent scans. Keep cancellation, sequence tracking and error handling separate for each reader. Use (board_id, boot_id, session_id, seq) as the unique key of one tag report.

Each ReaderClient buffers up to 1,024 notifications that your code has not read yet. When the buffer is full the SDK closes the connection, and the scan must be treated as incomplete. Keep callbacks short: hand database writes and CPU-heavy work to your own worker queue, in arrival order.

C# · connected ReaderClient instances
var result = await Task.WhenAll(
    readerA.ScanAsync(new InventoryRequest(Guid.NewGuid(), [1], MaxDurationMs: 5000) { Data = "epc_tid" }),
    readerB.ScanAsync(new InventoryRequest(Guid.NewGuid(), [1], MaxDurationMs: 5000) { Data = "epc_tid" }));
foreach (var scan in result)
    Console.WriteLine($"{scan.Session.BoardId}: {scan.ReceivedCount}/{scan.Session.LastSeq}, complete={scan.DataComplete}");
