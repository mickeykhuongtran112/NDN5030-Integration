Reader Control API

JSON-RPC 2.0 over Ethernet WSS or USB COM. Each Control API v1.4 method is listed with its .NET SDK function, parameters, result fields, errors and a request and response sample.

Transport and identification

Endpoint wss://<reader-ip>:8443/v1/control accepts Authorization: Bearer <device-token> during the WebSocket handshake. Each UTF-8 text message is one JSON object, maximum 8192 bytes, depth 16. Match RPC responses by id; receive asynchronous notifications continuously.

<device-token> is the token value in the host.json of the reader. The reader certificate is not issued by a public CA, so standard hostname and CA checks fail: compare the SHA-256 of the certificate (DER) with certificate_sha256 from host.json and trust only that certificate, as the SDK and the Python client on this page do.

A wrong or missing token is answered with HTTP 401. A second authenticated connection is answered with HTTP 503 while the first one is open. One controller connection is served per reader, over WSS or USB.

Continue only if api_major is 1. Keep board_id and boot_id. Check capabilities and module_operations before building control requests. Wait until state is idle before taking the lease. Request fields are also specified in the downloadable JSON Schema.

USB COM protocol

Open the USB COM port of the reader at 115200 8N1, with DTR asserted, RTS deasserted and no flow control. Send and receive LF-delimited UTF-8 JSON. The 8192-byte message limit excludes LF. The SDK implements framing and authentication in ReaderClient.FromUsb.

  1. Generate a random 16-byte nonce C and encode it as 32 lowercase hex characters. Send {"usb":"challenge","client":"C"}. The reader replies {"usb":"challenge","server":"S","proof":"<hex>"} with its own nonce S.
  2. Verify the server's proof with HMAC-SHA256 over ASCII NDN5030/usb/device/C/S. Use the 64 ASCII token characters from host.json as the key. Use the actual nonce strings in place of C and S.
  3. Send {"usb":"open","proof":"<hex>"} with the lowercase HMAC-SHA256 over ASCII NDN5030/usb/host/C/S. After {"usb":"ok"}, send hello and use the API catalog below.

Complete authentication within five seconds of the challenge. Keep the session active with a request such as status.get during idle periods. After 20 seconds without a request, on cable removal or when DTR drops, the reader ends the session without sending anything. The lease has its own five-second deadline.

Any other handshake failure is answered with {"usb":"error","reason":"authentication_failed"}: a nonce that is not 32 lowercase hex characters, a wrong proof, or an open step later than five seconds after the challenge. Start again from the challenge. After a session has ended the port stays open and the next request gets the same reply, so repeat the handshake.

USB control is part of the standard firmware image. The -comport image reserves the USB-C port for maintenance, so control is available over WSS only. If another controller is already connected, the reader answers the open step with {"usb":"error","reason":"reader_busy"}.

Control sequence

  1. Open an authenticated connection and call hello. Check api_major, board_id and the capability list.
  2. Poll status.get until state is idle. Stop if it is unknown. After power-on or a reboot the reader reports initializing while it prepares the RFID module.
  3. Call lease.acquire. Send lease.renew about every 1000 ms with the same lease_id. The SDK renews automatically while it holds the lease.
  4. Read or apply RF settings with module.call. Wait for idle between operations.
  5. Call inventory.start with a new UUID. Consume inventory.tags and inventory.state on the same connection.
  6. Call inventory.stop or let max_duration_ms end the session. Wait for inventory.state with state finished, confirm status.get.state is idle and check that every seq from 1 to last_seq arrived.
  7. Call lease.release when finished. Close the connection to let another application connect.

If the connection closes or the lease expires, the reader stops RF by itself. Tag messages are not stored on the reader for a later connection.

Request and response conventions

ItemRule
jsonrpcAlways "2.0".
idInteger from 1 to 9007199254740991, or a string of 1 to 64 characters. The reply carries the same id.
paramsObject. Use {} when the method has no parameters.
lease_idRequired by every method that needs the lease. The reader checks the lease before it looks up the method, so a misspelled or unknown method sent without a valid lease also gets -32001 lease_required, not -32601 method_not_found.
op_idUUID in the form xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx. It names one action. The same UUID with the same arguments is a retry. The same UUID with other arguments gets -32005 idempotency_conflict. The reader returns UUIDs in lowercase.
SuccessThe reply carries the request id and a result object.
ErrorThe reply carries error with code and message. message is a stable identifier such as reader_not_idle. id is null when the request could not be read.
NotificationA message with method and params and no id. It can arrive between a request and its reply.
LimitsOne JSON object per message, up to 8192 bytes and 16 levels deep. Wait for each reply before you send the next request: the reader holds at most 4 requests it has not yet processed (lease.renew and inventory.stop use a separate queue of 4) and closes the connection when a queue is full.

The samples on this page are illustrative. Values such as board_id, boot_id, lease_id and the UUIDs are placeholders. A reader returns its own values.

lease.acquire

Gives this connection control of the reader. Every method that changes RF, network or firmware state needs the returned lease_id. Calling it again on the owning connection refreshes the same lease.

.NET SDK: ReaderClient.AcquireLeaseAsync(). The SDK stores the lease and renews it every second. Lease: not required. Reader state: idle when the reader has no owner.

Parameters: none. Send params as {}.

Result fieldTypeDescription
lease_idstringOpaque token for this ownership. Send it unchanged.
ttl_msintegerTime to live: 5000 ms from this reply.

Errors: -32001 busy when the reader is not idle (for example initializing after power-on, or unknown).

lease.renew

Extends the lease to 5000 ms from now. Send it about every 1000 ms while the application holds control.

.NET SDK: automatic. ReaderClient renews in the background while it holds a lease. Lease: required. Reader state: any.

ParameterTypeDescription
lease_idstringRequired. Value returned by lease.acquire on this connection.
Result fieldTypeDescription
ttl_msintegerNew time to live: 5000 ms.

Errors: -32001 lease_required when the lease has expired or lease_id does not match.

When no renewal arrives for 5000 ms the reader stops inventory with reason lease_expired, discards an open firmware upload and frees the lease. The final inventory.state is then not sent. Read the result from status.get.session.

lease.release

Returns control. An active inventory is stopped with reason lease_released and an open firmware upload is discarded. The connection stays open.

.NET SDK: ReaderClient.ReleaseLeaseAsync(). Lease: required. Reader state: any.

ParameterTypeDescription
lease_idstringRequired. Value returned by lease.acquire on this connection.

Result: the same fields as status.get, captured just before the lease is freed.

Stop the session with inventory.stop and wait for finished before releasing. Once the lease is released the reader has no recipient for notifications: the final inventory.state is not sent, and tag reports that arrive while RF stops are counted in reported_drops, which marks the session partial. module.call

Firmware update sequence

  1. Read ota.status. With RF idle and a valid lease, send ota.begin with the signed application file size and lowercase SHA-256 hex of the entire file.
  2. Use the returned upload_id and exact byte offset for ota.chunk. Base64-encode each chunk within chunk_bytes (3072 decoded bytes). Read the acknowledged next offset. If a reply is lost, inspect ota.status before resuming.
  3. Send ota.finish to verify and stage the image, or ota.abort to discard an open upload. Inactivity for 30 seconds ends an unfinished upload.
  4. Restart with system.reboot. After reconnecting, use ota.status to compare running_version, running_elf_sha256, running_slot and boot_state with the staged result.

After booting a new image the reader confirms it once Ethernet, the control listener, USB and the RFID module have started and the reader is idle. Until then boot_state is pending_verify, and inventory.start, module.call, reader.set_config, network.set, ota.begin and system.reboot answer -32008 maintenance_busy. The same applies while an upload is open and after system.reboot has been accepted. If this does not happen within 20 seconds, the reader restarts into the previous image.

Notifications

NotificationSent when.NET SDK
inventory.tagsThe RFID module reports one tag observation during a session.onTag callback of ScanAsync → TagObservation.
inventory.stateA session changes state: running, stopping, finished or unknown.onEvent callback of ScanAsync, or ReadEventsAsync → ReaderEvent.Decode<InventorySession>().

Notifications are sent to the connection that holds the lease. Tag messages wait in a queue of 32 and state messages in a separate queue of 8, so inventory.state can arrive before the last tags. After the final inventory.state, keep reading until you have last_seq minus reported_drops tag messages, and stop after a bounded wait such as 2 seconds. Only then compare what you received with seq 1 to last_seq.

When the tag queue is full the reader counts the message in reported_drops and marks the session partial. The sequence number of the dropped message is skipped, so a gap in seq shows the loss.

Minimal client in Python

Python
"""Minimal NDN5030 Control API client: read tags on ANT1 for three seconds over WSS.

Usage:    python ndn5030_scan.py 192.168.77.2 host.json
Requires: Python 3.10 or later, pip install "websockets>=13"
"""
import asyncio
import hashlib
import json
import ssl
import sys
import uuid

from websockets.asyncio.client import connect


class Reader:
    """Match replies by id and keep notifications in arrival order."""

    def __init__(self, websocket):
        self.websocket, self.next_id, self.replies = websocket, 0, {}
        self.events = asyncio.Queue()
        self.receiver = asyncio.create_task(self.receive())

    async def receive(self):
        async for text in self.websocket:
            message = json.loads(text)
            if "method" in message:
                self.events.put_nowait(message)
            elif message.get("id") in self.replies:
                self.replies.pop(message["id"]).set_result(message)

    async def call(self, method, **params):
        self.next_id += 1
        reply = self.replies[self.next_id] = asyncio.get_running_loop().create_future()
        request = {"jsonrpc": "2.0", "id": self.next_id, "method": method, "params": params}
        await self.websocket.send(json.dumps(request))
        message = await asyncio.wait_for(reply, 5)
        if "error" in message:
            error = message["error"]
            raise RuntimeError(f"{method}: {error['code']} {error['message']}")
        return message["result"]


def pinned_tls(host, port, fingerprint):
    """Trust only the reader certificate whose SHA-256 is stored in host.json."""
    pem = ssl.get_server_certificate((host, port))
    if hashlib.sha256(ssl.PEM_cert_to_DER_cert(pem)).hexdigest() != fingerprint.lower():
        raise SystemExit("The reader certificate does not match host.json.")
    tls = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
    tls.check_hostname = False
    tls.load_verify_locations(cadata=pem)
    return tls


async def renew(reader, lease):
    while True:
        await asyncio.sleep(1)
        await reader.call("lease.renew", lease_id=lease)


async def scan(host, port, credential):
    tls = pinned_tls(host, port, credential["certificate_sha256"])
    headers = {"Authorization": "Bearer " + credential["token"]}
    url = f"wss://{host}:{port}/v1/control"
    async with connect(url, ssl=tls, additional_headers=headers) as websocket:
        reader = Reader(websocket)
        hello = await reader.call("hello")
        if hello["api_major"] != 1:
            raise SystemExit("Unsupported Control API version.")
        print(hello["board_id"], "firmware", hello["firmware"])

        while (state := (await reader.call("status.get"))["state"]) != "idle":
            if state == "unknown":
                raise SystemExit("Reader fault. Power-cycle the reader.")
            await asyncio.sleep(0.1)

        lease = (await reader.call("lease.acquire"))["lease_id"]
        renewal = asyncio.create_task(renew(reader, lease))
        try:
            await reader.call("inventory.start", lease_id=lease, op_id=str(uuid.uuid4()),
                              mode="scenario", antenna_sequence=[1], max_duration_ms=3000,
                              data="epc_tid")
            received, final = set(), None
            # The final state can arrive before the last tags. Read until last_seq is reached.
            while final is None or len(received) < final["last_seq"] - final["reported_drops"]:
                event = await asyncio.wait_for(reader.events.get(), 6)
                data = event["params"]
                if event["method"] == "inventory.tags":
                    received.add(data["seq"])
                    print(data["seq"], data["antenna"], data.get("epc_hex"), data.get("tid_hex"))
                elif event["method"] == "inventory.state":
                    if data["state"] in ("finished", "unknown"):
                        final = data
            while (status := await reader.call("status.get"))["state"] == "stopping":
                await asyncio.sleep(0.05)
            complete = (final["state"] == "finished" and final["outcome"] == "success"
                        and final["reported_drops"] == 0 and final["input_errors"] == 0
                        and received == set(range(1, final["last_seq"] + 1))
                        and status["state"] == "idle")
            print(final["reason"], f"{len(received)}/{final['last_seq']}", f"complete={complete}")
        finally:
            renewal.cancel()
            await reader.call("lease.release", lease_id=lease)


if __name__ == "__main__":
    with open(sys.argv[2], encoding="utf-8") as file:
        credential = json.load(file)
    asyncio.run(scan(sys.argv[1], int(sys.argv[3]) if len(sys.argv) > 3 else 8443, credential))
