Control API của reader

JSON-RPC 2.0 qua Ethernet WSS hoặc USB COM. Mỗi method của Control API v1.4 được trình bày kèm hàm .NET SDK, tham số, trường kết quả, lỗi và mẫu yêu cầu, phản hồi.

Transport và nhận diện

Endpoint wss://<reader-ip>:8443/v1/control nhận Authorization: Bearer <device-token> khi bắt tay WebSocket. Mỗi text message UTF-8 là một JSON object, tối đa 8192 byte, sâu 16 cấp. Ghép phản hồi theo id và nhận liên tục notification bất đồng bộ.

<device-token> là giá trị token trong host.json của reader. Chứng chỉ của reader không do CA công cộng cấp nên kiểm tra hostname và CA thông thường sẽ thất bại: hãy so SHA-256 của chứng chỉ (DER) với certificate_sha256 trong host.json và chỉ tin đúng chứng chỉ đó, như SDK và client Python trên trang này vẫn làm.

Token sai hoặc thiếu nhận HTTP 401. Kết nối xác thực thứ hai nhận HTTP 503 khi kết nối đầu còn mở. Mỗi reader phục vụ một kết nối controller, qua WSS hoặc USB.

Chỉ tiếp tục khi api_major = 1. Lưu lại board_id và boot_id. Kiểm tra capabilities, module_operations trước khi tạo lệnh. Chờ state là idle rồi mới lấy lease. Trường yêu cầu cũng được định nghĩa trong JSON Schema tải kèm.

Giao thức USB COM

Mở cổng USB COM của reader ở 115200 8N1, bật DTR, tắt RTS và flow control. Gửi nhận JSON UTF-8 theo dòng LF. Giới hạn 8192 byte chưa tính LF. SDK xử lý framing và xác thực qua ReaderClient.FromUsb.

  1. Sinh nonce C ngẫu nhiên 16 byte, mã hoá thành 32 ký tự hex thường. Gửi {"usb":"challenge","client":"C"}. Reader trả lời {"usb":"challenge","server":"S","proof":"<hex>"} kèm nonce S của reader.
  2. Xác minh proof server bằng HMAC-SHA256 trên ASCII NDN5030/usb/device/C/S. Dùng 64 ký tự ASCII của token trong host.json làm khoá. Thay C và S bằng nonce thực tế.
  3. Gửi {"usb":"open","proof":"<hex>"} với HMAC-SHA256 hex thường trên ASCII NDN5030/usb/host/C/S. Khi nhận {"usb":"ok"}, gửi hello rồi dùng API bên dưới.

Hoàn thành xác thực trong năm giây kể từ challenge. Dùng yêu cầu như status.get để giữ phiên khi idle. Sau 20 giây không có yêu cầu, khi rút cáp hoặc hạ DTR, reader kết thúc phiên mà không gửi gì. Lease có thời hạn riêng năm giây.

Mọi lỗi bắt tay khác được trả lời bằng {"usb":"error","reason":"authentication_failed"}: nonce không phải 32 ký tự hex thường, proof sai, hoặc bước open tới muộn hơn năm giây sau challenge. Khi đó hãy bắt đầu lại từ challenge. Sau khi phiên kết thúc, cổng COM vẫn mở và yêu cầu kế tiếp nhận cùng phản hồi này, vì vậy hãy bắt tay lại.

Firmware 0.5.0 cung cấp cổng COM ứng dụng của reader qua USB-C. Nếu đã có controller kết nối, reader trả {"usb":"error","reason":"reader_busy"} ở bước open.

Trình tự điều khiển

  1. Mở kết nối xác thực và gọi hello. Kiểm tra api_major, board_id và danh sách capability.
  2. Gọi status.get cho tới khi state là idle. Dừng nếu là unknown. Sau khi cấp nguồn hoặc reboot, reader báo initializing trong lúc chuẩn bị module RFID.
  3. Gọi lease.acquire. Gửi lease.renew khoảng mỗi 1000 ms với cùng lease_id. SDK tự gia hạn khi đang giữ lease.
  4. Đọc hoặc áp dụng cấu hình RF bằng module.call. Chờ idle giữa các thao tác.
  5. Gọi inventory.start với UUID mới. Nhận inventory.tags và inventory.state trên cùng kết nối.
  6. Gọi inventory.stop hoặc để max_duration_ms kết thúc phiên. Chờ inventory.state có state là finished, xác nhận status.get.state là idle và kiểm tra đã nhận đủ mọi seq từ 1 đến last_seq.
  7. Gọi lease.release khi xong. Đóng kết nối để ứng dụng khác truy cập reader.

Đóng kết nối hoặc để lease hết hạn sẽ yêu cầu reader dừng phiên inventory đang chạy. Sau khi kết nối lại, đọc status.get để kiểm tra trạng thái RF và kết quả phiên. Reader không phát lại các bản tin tag đã bỏ lỡ.

Trình tự cập nhật firmware

Với reader sản phẩm, chọn file ứng dụng đã ký ndn5030.bin. Sau khi khởi động lại, kiểm tra phiên bản đang chạy trong hello.firmware và ota.status.running_version. Với bản phát hành này, cả hai đều trả 0.5.0.

  1. Đọc ota.status. Khi RF idle và có lease hợp lệ, gửi ota.begin cùng kích thước file ứng dụng đã ký và SHA-256 hex thường của toàn file.
  2. Dùng upload_id trả về và offset byte chính xác cho ota.chunk. Mã hoá base64 từng chunk trong giới hạn chunk_bytes (3072 byte sau giải mã). Đọc offset tiếp theo. Khi mất phản hồi, xem ota.status trước khi tiếp tục.
  3. Gửi ota.finish để xác minh và chọn image, hoặc ota.abort để bỏ upload đang mở. Phiên upload chưa xong hết hạn sau 30 giây không có dữ liệu.
  4. Khởi động lại bằng system.reboot. Sau khi kết nối lại, dùng ota.status để so running_version, running_elf_sha256, running_slot và boot_state với kết quả đã stage.

Sau khi boot image mới, reader xác nhận image khi Ethernet, cổng điều khiển, USB và module RFID đã khởi động xong và reader ở idle. Trước lúc đó boot_state là pending_verify, và inventory.start, module.call, reader.set_config, network.set, ota.begin cùng system.reboot trả -32008 maintenance_busy. Điều này cũng đúng khi đang có phiên upload mở và sau khi system.reboot đã được chấp nhận. Nếu việc này không xong trong 20 giây, reader khởi động lại về image trước.

"""Minimal NDN5030 Control API client: read tags on ANT1 for three seconds over WSS.

Usage:    python ndn5030_scan.py 192.168.77.2 host.json
Requires: Python 3.10 or later, pip install "websockets>=13"
"""
import asyncio
import hashlib
import json
import ssl
import sys
import uuid

from websockets.asyncio.client import connect


class Reader:
    """Match replies by id and keep notifications in arrival order."""

    def __init__(self, websocket):
        self.websocket, self.next_id, self.replies = websocket, 0, {}
        self.events = asyncio.Queue()
        self.receiver = asyncio.create_task(self.receive())

    async def receive(self):
        async for text in self.websocket:
            message = json.loads(text)
            if "method" in message:
                self.events.put_nowait(message)
            elif message.get("id") in self.replies:
                self.replies.pop(message["id"]).set_result(message)

    async def call(self, method, **params):
        self.next_id += 1
        reply = self.replies[self.next_id] = asyncio.get_running_loop().create_future()
        request = {"jsonrpc": "2.0", "id": self.next_id, "method": method, "params": params}
        await self.websocket.send(json.dumps(request))
        message = await asyncio.wait_for(reply, 5)
        if "error" in message:
            error = message["error"]
            raise RuntimeError(f"{method}: {error['code']} {error['message']}")
        return message["result"]


def pinned_tls(host, port, fingerprint):
    """Trust only the reader certificate whose SHA-256 is stored in host.json."""
    pem = ssl.get_server_certificate((host, port))
    if hashlib.sha256(ssl.PEM_cert_to_DER_cert(pem)).hexdigest() != fingerprint.lower():
        raise SystemExit("The reader certificate does not match host.json.")
    tls = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
    tls.check_hostname = False
    tls.load_verify_locations(cadata=pem)
    return tls


async def renew(reader, lease):
    while True:
        await asyncio.sleep(1)
        await reader.call("lease.renew", lease_id=lease)


async def scan(host, port, credential):
    tls = pinned_tls(host, port, credential["certificate_sha256"])
    headers = {"Authorization": "Bearer " + credential["token"]}
    url = f"wss://{host}:{port}/v1/control"
    async with connect(url, ssl=tls, additional_headers=headers) as websocket:
        reader = Reader(websocket)
        hello = await reader.call("hello")
        if hello["api_major"] != 1:
            raise SystemExit("Unsupported Control API version.")
        print(hello["board_id"], "firmware", hello["firmware"])

        while (state := (await reader.call("status.get"))["state"]) != "idle":
            if state == "unknown":
                raise SystemExit("Reader fault. Power-cycle the reader.")
            await asyncio.sleep(0.1)

        lease = (await reader.call("lease.acquire"))["lease_id"]
        renewal = asyncio.create_task(renew(reader, lease))
        try:
            await reader.call("inventory.start", lease_id=lease, op_id=str(uuid.uuid4()),
                              mode="scenario", antenna_sequence=[1], max_duration_ms=3000,
                              data="epc_tid")
            received, final = set(), None
            # The final state can arrive before the last tags. Read until last_seq is reached.
            while final is None or len(received) < final["last_seq"] - final["reported_drops"]:
                event = await asyncio.wait_for(reader.events.get(), 6)
                data = event["params"]
                if event["method"] == "inventory.tags":
                    received.add(data["seq"])
                    print(data["seq"], data["antenna"], data.get("epc_hex"), data.get("tid_hex"))
                elif event["method"] == "inventory.state":
                    if data["state"] in ("finished", "unknown"):
                        final = data
            while (status := await reader.call("status.get"))["state"] == "stopping":
                await asyncio.sleep(0.05)
            complete = (final["state"] == "finished" and final["outcome"] == "success"
                        and final["reported_drops"] == 0 and final["input_errors"] == 0
                        and received == set(range(1, final["last_seq"] + 1))
                        and status["state"] == "idle")
            print(final["reason"], f"{len(received)}/{final['last_seq']}", f"complete={complete}")
        finally:
            renewal.cancel()
            await reader.call("lease.release", lease_id=lease)


if __name__ == "__main__":
    with open(sys.argv[2], encoding="utf-8") as file:
        credential = json.load(file)
    asyncio.run(scan(sys.argv[1], int(sys.argv[3]) if len(sys.argv) > 3 else 8443, credential))
