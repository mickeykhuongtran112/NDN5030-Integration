.NET SDK trực tiếp

Tích hợp Ndn5030.Client 0.8.2 vào ứng dụng .NET 10. Một ReaderClient giữ kết nối tới một reader.

Cài package

Tạo project console .NET 10, hoặc bắt đầu từ project có sẵn trong thư mục sdk\ReadTags của gói. Thêm thư mục sdk của gói đã giải nén làm nguồn NuGet cục bộ; thay đường dẫn bên dưới bằng đường dẫn của bạn. Ndn5030.Client phụ thuộc System.IO.Ports 10.0.0, nên nuget.org hoặc feed nội bộ của bạn cũng phải truy cập được khi restore.

PowerShell
dotnet nuget add source "D:\NDN5030\sdk" --name NDN5030
dotnet add package Ndn5030.Client --version 0.8.2

Ví dụ inventory có giới hạn

Lưu đoạn sau vào Program.cs. Đối số đầu là địa chỉ reader: URL WSS khi dùng Ethernet, hoặc tên cổng USB COM như COM7. Đối số thứ hai là đường dẫn tệp host.json của reader. Callback tag được gọi từ vòng lặp SDK nhận thông báo của reader, nên cần trả về nhanh.

C#
using Ndn5030.Client;

string endpoint = args[0];
string credentials = args[1];
await using var reader = endpoint.StartsWith("wss://", StringComparison.OrdinalIgnoreCase)
    ? new ReaderClient(ProvisionedIdentity.Load(new Uri(endpoint), credentials))
    : ReaderClient.FromUsb(ProvisionedIdentity.LoadUsb(endpoint, credentials));
var hello = await reader.ConnectAsync();
var config = await reader.GetReaderConfigurationAsync();
Console.WriteLine($"{hello.BoardId}, firmware {hello.Firmware}, ceiling {config.PowerLimitDbm} dBm");
using var stop = new CancellationTokenSource();
Console.CancelKeyPress += (_, e) => { e.Cancel = true; stop.Cancel(); };
var request = new InventoryRequest(Guid.NewGuid(), [1, 2, 3, 4], MaxDurationMs: 5000) { Data = "epc_tid" };
var result = await reader.ScanAsync(request,
    tag => Console.WriteLine($"ANT{tag.Antenna}   {tag.EpcHex}   {tag.TidHex}"), stop.Token);
Console.WriteLine($"{result.Session.Reason}   {result.ReceivedCount}/{result.Session.LastSeq}   complete={result.DataComplete}");
await reader.ReleaseLeaseAsync();

Lưu ý. Mỗi reader chỉ phục vụ một controller tại một thời điểm. Hãy chọn Disconnect trong TCPHost trước khi chạy ví dụ trên cùng reader.

PowerShell
dotnet run -- wss://192.168.77.2:8443/v1/control D:\station\host.json

ScanAsync lấy lease, bắt đầu inventory, nhận các thông báo tag và khi kết thúc sẽ kiểm tra đã nhận đủ mọi số thứ tự cho tới số cuối mà reader báo. Huỷ token bạn truyền vào sẽ gửi Stop cho scan đó; lời gọi vẫn trả về kết quả cuối. ReceivedCount đếm số observation; DataComplete yêu cầu phiên kết thúc thành công, sequence liên tục, không drop và không lỗi đầu vào.

Chờ reader sẵn sàng

Sau khi cấp nguồn hoặc khởi động lại, reader báo initializing trong lúc chuẩn bị module RFID. Lúc này AcquireLeaseAsync và ScanAsync ném ReaderRpcException mã -32001 với message busy. Hãy chờ idle sau ConnectAsync.

C#
ReaderStatus status;
while ((status = await reader.GetStatusAsync()).State is not ("idle" or "unknown"))
    await Task.Delay(100);
if (status.State == "unknown")
    throw new InvalidOperationException($"Reader fault: {status.Reason}");
  • Khôi phục từ trạng thái unknown

Lệnh cấu hình

C#
await reader.AcquireLeaseAsync();
var power = (await reader.GetPowerAsync()).Decode<int[]>();
Console.WriteLine(string.Join(", ", power));
await reader.ReleaseLeaseAsync();

Gọi AcquireLeaseAsync trước thao tác module. GetReaderConfigurationAsync trả cấu hình reader đang ghi nhớ, GetPowerAsync truy vấn module RFID. Để khôi phục được khi mất phản hồi của một lệnh thay đổi cấu hình, hãy tự tạo một UUID, lưu lại và truyền vào CallModuleAsync(operation, args, operationId); khi đó GetModuleResultAsync trả về kết quả đã lưu cho UUID này.

  • Toàn bộ thao tác RF kèm tham số và kết quả

Nhiều reader đồng thời

Tạo một ReaderClient cho mỗi reader. Kiểm tra board ID trước khi chạy các scan đồng thời. Mỗi reader có cancellation, bộ đếm sequence và xử lý lỗi riêng. Dùng (board_id, boot_id, session_id, seq) làm khoá duy nhất của một lượt báo cáo tag.

Mỗi ReaderClient đệm tối đa 1.024 thông báo mà mã của bạn chưa đọc. Khi bộ đệm đầy, SDK đóng kết nối và scan phải được coi là chưa đủ dữ liệu. Giữ callback ngắn: chuyển việc ghi database và xử lý nặng sang hàng đợi worker của bạn, theo đúng thứ tự nhận.

C# · connected ReaderClient instances
var result = await Task.WhenAll(
    readerA.ScanAsync(new InventoryRequest(Guid.NewGuid(), [1], MaxDurationMs: 5000) { Data = "epc_tid" }),
    readerB.ScanAsync(new InventoryRequest(Guid.NewGuid(), [1], MaxDurationMs: 5000) { Data = "epc_tid" }));
foreach (var scan in result)
    Console.WriteLine($"{scan.Session.BoardId}: {scan.ReceivedCount}/{scan.Session.LastSeq}, complete={scan.DataComplete}");
